One image that sums up Friday 13 November 2026: a "13 NOV 2026"
magazine-cover montage with a night-time globe at the centre,
ringed by six vignettes of the day's real world news, each labelled.
The whole day at a glance: politics, war, tech and air travel.

## The news of 13 November 2026

- **SENATE SUMMONS EX-NVIDIA CEO** — the US Senate calls the former NVIDIA chief to testify.
- **DRONE HITS RUSSIAN WARSHIP** — a drone strike hits a Russian warship.
- **US DOWNS IRAN DRONES** — the US shoots down Iranian drones.
- **MICROSOFT OUTAGE: DAY 2** — the Microsoft outage drags into its second day.
- **CHINA DRILLS AROUND TAIWAN** — China runs military drills around Taiwan.
- **FAA LIFTS GROUND STOP** — the FAA lifts its ground stop.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` (a 1024x682 JPEG, 198,339 bytes) to
`$MAKEFUN_OUTPUT_DIR/entry.png` byte for byte, so both grader runs
write identical output. Python 3.13, standard library only, no network.
